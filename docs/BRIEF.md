# Tari November 2026: early-launch triage

Checked 2026-11-20 00:34 UTC against the forum HTML and live Discourse JSON.

## Target

First-to-Launch bonus, rather than a ranked November prize. Sponsor wants usable Ootle mainnet projects and public outreach.

- Bonus: 100,000 XTM for each of the first 20 eligible people; not a fixed USD payout.
- Visible thread: 13 distinct project launch claims from 12 people. One duplicate update and one funding request are excluded. Claims are not verified awards; availability is not guaranteed.
- Ranking uses contract publication transaction time, not forum posting order.
- Deadline text literally says “midnight November 11:11:11 November 21st UTC (one week after the launch)”. These conflict. Treat November 21 00:00 UTC (01:00 WAT) as a conservative working cutoff, not an organizer-confirmed interpretation. About 23 hours 25 minutes remained at this check.

- [ ] New November work, fitting MVP theme; November expressly permits substantial innovation on previous entries.

- [ ] Tari payout address.

- [ ] One complete submission post in November thread.
- [ ] Contract actually published on Ootle mainnet, with transaction/time proof saved.
- [ ] App configured for mainnet and fully reviewable before bonus cutoff.
- [ ] Separate bonus-thread post linking deployment and original entry.

AI coding is explicitly permitted in general-rule clarifications. November's specific code-reuse permission modifies the older general prohibition.

Use a tiny scope and existing infrastructure. No paid domain or external paid API is inherently required. Actual funding route and fees need verification before spending. No official remaining-slot tally or guaranteed acceptance was found.

Judging: Council review/vote, theme adherence; no numerical weights published in the rules reviewed. Main contest awards are separate from the first-launch bonus. Fit: provisionally workable, with mainnet funding/access still unverified. No other event schedule was supplied.

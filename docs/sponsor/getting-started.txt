Prerequisites
Section titled “Prerequisites”
Before you begin, ensure you have the following installed:
Rust:
 The Rust programming language and Cargo package manager. We recommend using
rustup
 to manage your Rust toolchains.
You’ll need the
wasm32-unknown-unknown
 target.

Tari Ootle CLI (Optional but Recommended):
 For local testing and publishing templates, we suggest using the Tari Ootle CLI.
Install it with

 (this creates a binary called
tari
).
